## Overview

Cloud 66 has three products. Each one deploys your code to infrastructure in your own cloud account or data center, and manages your application from there. Cloud 66 doesn't host your application itself.

| Product | For | Deploys to | You'll need |
|---|---|---|---|
| Cloud 66 for Rails | Ruby on Rails applications | Servers in your cloud account, or your own servers | A cloud provider account or your own servers, and a Git repository |
| Cloud 66 Deploy | Containerized applications, such as Node.js, PHP, Python, Go, Java, and Rails in containers | Kubernetes, on servers in your cloud account | A cloud provider account and a Git repository |
| Cloud 66 Sites | Static sites, such as Jekyll, Hugo, Gatsby and Next.js static exports | Object storage in your cloud account, served through a CDN | A cloud provider account with S3-compatible object storage, and a Git repository |

When you start deploying your code with Cloud 66, it detects your application's framework and chooses the right deployment strategy for you. See [Framework support](/deploy/build-and-config/framework-support) for the full list of frameworks.

## Which product fits my app?

- **A Rails application:** Cloud 66 for Rails. If you already run your Rails application in containers, you can use Cloud 66 Deploy instead.
- **A static site, or a Next.js app built as a static export:** Cloud 66 Sites. A Next.js app that uses server-side rendering or API routes needs Cloud 66 Deploy.
- **Anything else that runs in a container:** Cloud 66 Deploy.

## Cloud 66 for Rails

Cloud 66 for Rails deploys your Rails application to virtual machines or bare metal servers, on any supported cloud provider or in your own data center, and manages the entire lifecycle of your application. Read more in the [Rails documentation](https://help.cloud66.com/rails/).

## Cloud 66 Deploy

Cloud 66 Deploy builds your application into containers, deploys it to a Kubernetes cluster and manages the entire lifecycle of your application. It supports frameworks including Node.js, PHP, Python, Go and Java, and can also deploy Rails applications if you prefer to run them in containers. Read more in the [Deploy documentation](https://help.cloud66.com/deploy/).

Cloud 66 Deploy v2 is the current version. Deploy v3 is available as an early access product. See [Deploy v2 vs v3](/deploy/getting-started/deploy-v2-vs-v3) to compare them.

## Cloud 66 Sites

Cloud 66 Sites builds your static site, stores the files in S3-compatible object storage in your own cloud account and serves them through a CDN. It supports static site generators including Jekyll, Hugo, Gatsby and Next.js. Read more in the [Sites documentation](https://help.cloud66.com/sites/).
